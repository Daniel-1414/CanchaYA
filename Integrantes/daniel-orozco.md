## Mi objetivo

Quiero fortalecer mi perfil como desarrollador **Frontend**, sin perder de vista el análisis de requisitos, para construir páginas web y aplicaciones completas, bien probadas y fáciles de mantener.

---

## Frontend

| Tecnología | Por qué quiero aprenderla |
|------------|---------------------------|
| **TypeScript** | Para escribir JavaScript más seguro y detectar errores antes de ejecutar. |
| **React** | Para crear interfaces por componentes, reutilizables y escalables. |
| **Tailwind CSS** | Para diseñar interfaces responsive de forma rápida y consistente. |
| **Next.js** | Para construir aplicaciones web completas con rutas, renderizado y buen rendimiento. |



## Backend y datos

| Tecnología | Por qué quiero aprenderla |
|------------|---------------------------|

| **PostgreSQL** | Para profundizar en SQL, vistas, procedimientos almacenados y transacciones. |
| **Firebase** | Para seguir usando servicios en la nube en mis apps. |
